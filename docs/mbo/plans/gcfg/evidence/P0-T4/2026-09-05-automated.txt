GitHub App credential toolkit — create an App by manifest, mint installation tokens

Usage:
  ghapp [flags]
  ghapp [command]

Available Commands:
  completion  Generate the autocompletion script for the specified shell
  create      Create a GitHub App via the manifest flow and store its key (0600)
  doctor      Check the store, key, App JWT, installations, and (with --repo) a real token
  help        Help about any command
  install     Open the App's install page, then record where it is installed
  status      Show stored Apps, key file modes, and recorded installations (no secrets)
  token       Mint an installation token; prints ONLY the token on stdout
  version     Show version information

Flags:
      --app string          App slug when more than one is stored
      --config-dir string   where apps.json and the PEMs live (0700) (default "~/.config/ghapp")
  -h, --help                help for ghapp

Use "ghapp [command] --help" for more information about a command.
