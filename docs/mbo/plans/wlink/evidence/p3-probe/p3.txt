## Why stdlib, not a DNS library
net.Resolver preserves exactly the distinctions wlink needs, so no new dependency:
  blackhole -> IsTimeout=true  IsNotFound=false  => Silent
  NXDOMAIN  -> IsTimeout=false IsNotFound=true   => NoAddress
  SERVFAIL  -> neither                            => Unhelpful (reachable)
