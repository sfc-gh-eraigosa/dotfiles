# Evaluation: Agent Orchestration

This document provides instructions for evaluating the `tmux-mgr` Integrated Agent Orchestration feature.

## Goal
Prove that `tmux-mgr` can successfully:
1.  **Spawn** multiple agents into isolated Git worktrees/tmux panes using a natural language task description.
2.  **Execute** the tasks within the isolated panes.
3.  **Fan-In** detailed findings from `RESULT.md`.
4.  **Cleanup** the isolated environments.

## Evaluation Steps (Verification Script)

To evaluate the tool, execute the following sequence:

### 1. Execution
Spawn two agents directly with their tasks defined in the command line.

-   **Agent A:**
    ```bash
    tmux-mgr agent start generalist --task-description "Write 'Hello from Agent A' to RESULT.md and exit."
    ```
-   **Agent B:**
    ```bash
    tmux-mgr agent start generalist --task-description "Write 'Hello from Agent B' to RESULT.md and exit."
    ```

### 2. Monitoring
Check the status of the physical sessions:
```bash
tmux-mgr agent list
```
Verify that two sessions are listed and that their `WorktreePath` exists in `~/.config/tmux-mgr/worktrees/`.

### 3. Results (Fan-In)
Wait for the sub-agents to finish (the panes will close or the processes will terminate). Retrieve the results:
```bash
tmux-mgr agent complete <session_id_from_list_for_A>
tmux-mgr agent complete <session_id_from_list_for_B>
```

### 4. Finalization & Cleanup
Confirm that the results match the expectations ("Hello from Agent A" and "Hello from Agent B").
Cleanup the sessions:
```bash
tmux-mgr agent cleanup <session_id_A>
tmux-mgr agent cleanup <session_id_B>
```

## Success Criteria
- [ ] Tmux window splits twice, creating two new panes.
- [ ] Two Git worktrees are created under `~/.config/tmux-mgr/worktrees/`.
- [ ] `RESULT.md` files are generated by the sub-agents in their respective worktrees.
- [ ] The `agent complete` command successfully retrieves the "Hello World" outputs.
- [ ] Worktrees and session tracking files are removed after `agent cleanup` is run.
