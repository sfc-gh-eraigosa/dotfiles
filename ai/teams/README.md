# AI Agent Teams

This directory organizes specialized agent teams under `ai/teams/`. Each subdirectory is a self-contained team whose agents share a common domain, model tier policy, and handoff protocol.

See [`MODEL_PARAMS.md`](./MODEL_PARAMS.md) for the full model-parameter convention used in every agent file.

## Install & Use

`opt/scripts/system/install_ai_teams.sh` (alias `sync-teams`, wired into `install.sh`)
transforms each persona into a native agent for all four tools and degrades gracefully
when a tool is absent:

| Tool | Installed to | Invoke |
|------|--------------|--------|
| Claude Code | `~/.claude/agents/teams/<team>/<role>.md` | `@agent-<team>-<role>` |
| Gemini CLI | `~/.gemini/agents/teams/<team>/<role>.md` | `<team>-<role>` |
| Antigravity | `~/.config/antigravity/agents/<team>-<role>.yaml` | `<team>-<role>` |
| Ollama | Modelfile → `ollama create teams-<team>-<role>` | `teams-<team>-<role>` |

Run **`/team <team\|squad>`** (Claude + Gemini) to route a task to the right team and
member. The full routing table lives in [`INDEX.md`](./INDEX.md); cross-team **squads**
are defined in [`teams.yaml`](./teams.yaml). Routing artifacts are regenerated by
`gen-index.sh`; source consistency is enforced by `validate.sh`.

## Model Parameter Format

Each agent declares an abstract **`tier:`** in its YAML frontmatter (`fast | standard |
think | deep-think`) — never a concrete model. The installer resolves the tier through
[`model-map.yaml`](./model-map.yaml) into each tool's model + effort/temperature, so model
churn is fixed in one place. See [`MODEL_PARAMS.md`](./MODEL_PARAMS.md) for the full
mapping and frontmatter schema.

## Adding a New Team

1. Create a subdirectory: `ai/teams/<team-name>/`
2. Add a row for the team to [`teams.yaml`](./teams.yaml) (display, symbol, color, default_tier).
3. Add 3–5 agent `the_*.md` files using the YAML frontmatter schema in
   [`MODEL_PARAMS.md`](./MODEL_PARAMS.md) (incl. `tier`, `file_globs`, `use_when`,
   `avoid_when`, `compose`). Optionally add cross-team `squads` entries in `teams.yaml`.
4. Run `bash ai/teams/validate.sh` (consistency) and `bash ai/teams/gen-index.sh`
   (regenerates `INDEX.md`, per-team + root `GEMINI.md` + `CLAUDE.md` symlinks, and the
   `/team` command). Add the team to the table above.
5. `sync-teams` (or rerun `install.sh`) to emit the new agents for all four tools.

## Compatibility

Agents in this directory are compatible with:
- **Claude Code** — reads `claude:` model line + `Context-Strategy` for effort hints
- **Gemini CLI** — reads `gemini:` model line + `think_budget` hint
- **Anti-Gravity CLI** — reads `antigravity:` model line + `effort` hint
- **Ollama** (local) — reads `ollama:` model line as local fallback
