# Miscellaneous (opt/scripts/misc)

- `open-url`: Open a URL/file in the platform's default browser — `open` (macOS), `wslview`/`explorer.exe`/`cmd.exe` (WSL), `xdg-open` (Linux). Used by the git-safe-sync skill's "open the PR?" step; exits non-zero on headless sessions.
- `agm.disable_sh`: Antigravity Module disable script.
- `antigravity_arm.sh`: Antigravity Arm activation script.
- `tmuxinator.zsh`: Zsh completion/helper for Tmuxinator.
- `toggle_browser.scpt`: AppleScript for browser switching.
