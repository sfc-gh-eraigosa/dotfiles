# Scripts Registry (opt/scripts)

This directory contains categorized utility scripts. Each category has its own registry for deeper discovery.

## Categories

- [Git Utilities](./git/AGENTS.md): Basic git operations and maintenance.
- [Docker & Containerization](./docker/AGENTS.md): Setup and helpers for Docker/Dind.
- [System & Environment Setup](./system/AGENTS.md): OS-level setup and package management.
- [Networking & Remote Access](./network/AGENTS.md): Proxy, SSH, and certificate management.
- [Data & File Management](./data/AGENTS.md): Cloud storage, SQL, and data transformation.
- [Miscellaneous](./misc/AGENTS.md): Themes, completions, and specialized modules.

## PATH Management

All subdirectories in `opt/scripts/` are automatically added to your `$PATH` via your shell profile.
