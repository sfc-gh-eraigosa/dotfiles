# Tools Registry (opt/bin)

This directory contains a variety of utility scripts and binaries. Use this registry to discover the right tool for your task.

## Git Utilities

- `git_add.sh`, `git_branch.sh`, `git_pull.sh`: Basic git operations.
- `git-local-master.sh`: Helper for managing local master branches.
- `git-reset.sh`: Script for resetting git state.
- `git-rm-mybranches.sh`: Cleanup utility for personal branches.
- `git-signoff.sh`: Adds sign-off to commits.
- `git-sizer`: Binary for analyzing git repository size.
- `setup_git_alias.sh`: Configures git aliases.
- `update_origin.sh`: Updates the remote origin URL.

## Docker & Containerization

- `docker_machine_setup.sh`: Sets up Docker Machine.
- `docker_up.sh`: Brings up Docker containers.
- `dockerd-entrypoint.sh`: Entrypoint for Docker daemon.
- `prepare_node_docker.sh`: Prepares a Node.js environment for Docker.
- `setup_dindc_alias.sh`: Setup for Docker-in-Docker containers.
- `setup_docker_perms.sh`: Fixes Docker socket permissions.
- `setup_ruby-docker.sh`: Setup for Ruby in Docker.

## System & Environment Setup

- `google-cli-setup.sh`: Installs and configures Google Cloud SDK.
- `gemini_install.sh`: Installation script for Gemini.
- `terminal-theme.sh`: Switches or configures terminal themes.
- `vault-login.sh`, `vault-setup.sh`: HashiCorp Vault management.
- `nvm`: Node Version Manager helper.
- `storage-setup.sh`: Configures storage mounts.

## Networking & Remote Access

- `proxy.sh`: Script for managing proxy settings.
- `remote-setup.sh`: Sets up remote environment.
- `ssh-find`: Helper for finding SSH hosts.
- `sshd_run.sh`: Runs the SSH daemon.
- `import-cert.sh`: Imports SSL certificates.

## Data & File Management

- `rclone_sync.sh`, `install_rclone.sh`, `install_rclone_service.sh`: Rclone utilities for cloud storage.
- `y2j.sh`: YAML to JSON converter.
- `find-badfiles.sh`: Identifies problematic files.
- `install_snowsql.sh`: Installs Snowflake CLI.

## Miscellaneous

- `agm.sh`: Antigravity Module? (Check content for details).
- `antigravity_arm.sh`: Related to `agm.sh`.
- `discuss`: Binary tool (Check `discuss --help`).
- `perf-toggle.sh`: Toggles performance modes.
- `toggle_browser.scpt`: AppleScript for browser switching.
- `tmuxinator.zsh`: Zsh completion/helper for Tmuxinator.
