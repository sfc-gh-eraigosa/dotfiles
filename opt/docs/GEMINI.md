# Legacy Documentation (opt/docs)

This directory contains reference documentation for various tools and setups.

## Available Documentation

- `ubuntu_tools.md`: Comprehensive list of tools for Ubuntu.
- `cruton.md`: Documentation for Crouton (Chromium OS).
- `zsh_andtools.md`: Zsh and related tools setup.
- `macOS-tips.md`: Tips and tricks for macOS.
- `virtualization.md`: Documentation on virtualization setups.
- `git/`: Specialized git documentation (e.g., repo splitting).

*Note: Much of this documentation may be legacy and should be verified against current environment state.*
